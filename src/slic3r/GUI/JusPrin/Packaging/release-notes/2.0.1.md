JusPrin 2.0.1 speaks your language, connects more printers from the printer chat, and fixes printers that could not be added in languages that write decimals with a comma.

## New

- **JusPrin in your language.** JusPrin's own screens, the AI chat and Home are translated into the 22 languages OrcaSlicer ships. Choose the language in Preferences › Appearance › Language. Numbers follow it too, for example "0,4 mm" in German. The translations are made by machine, so some wording may read oddly.
- **More printers connect from the printer chat.** The printer chat can now connect every connection type OrcaSlicer's printer settings offer, not only Klipper (Moonraker) and OctoPrint. This includes Elegoo Centauri Carbon and Centauri Carbon 2 printers (Elegoo Link). The chat cannot finish Repetier, UltiMaker, or PrusaLink with a user name and password, and tells you where to set those up instead. Obico, SimplyPrint and 3DPrinterOS still need their own sign-in.
- **Reporting errors.** When something goes wrong that you can't fix yourself, JusPrin shows one message, "Something went wrong on our side". You can see the whole report, then press Report to JusPrin team, or tick "From now on, report errors like this automatically". You can also turn this on or off in Preferences › Updates › Error reports. It is off until you turn it on.

## Fixed

- In languages that write decimals with a comma, such as German, French, Spanish, Portuguese and Russian, the add-printer form showed no nozzle sizes for most printers, so the printer could not be added. Bed sizes such as 233.5 mm were also read as 233 mm, and a 0.4 mm nozzle in an opened 3MF file was read as 0. This always happened on Windows.
- A calibration test started from one of your projects lost that project and its chat.
- A project could save itself again after sitting idle, with nothing changed.
- A file the AI chat refused to attach (too large, or a kind it can't read) stopped the project from saving until you removed it.
- If JusPrin couldn't write its settings file, signing in or saving an API key looked like it worked, and was lost when you quit. JusPrin now shows an error instead.
- Deleting your account now waits until AI has finished replying in any chat.
- A chat whose account or API key was removed showed the wrong model in its greyed-out model picker. It now shows the model the chat ran on.
- When AI prepared a print, it could keep checking the slice it had just started, again and again, while the slice ran.

## What JusPrin now sends

- **When the app starts**, it tells JusPrin's server once that it started: a random number made on the first start, the app's version and the name of your operating system. Nothing in it names you, and no sign-in goes with it. It is not sent in stealth mode.
- **Error reports and crashes** go to JusPrin's error tracker (Sentry) only when you press Report to JusPrin team, or when you have turned on automatic reports. A report holds where in the app the error happened, the steps just before it (never what you typed or what AI said), your operating system and the app's log for that run. A crash report also holds the app's state at the moment it crashed. With automatic reports off, a crash report stays on your computer.

## Downloads

- **Windows (64-bit):** the installer, or the portable .zip, which runs without installing.
- **Mac:** one disk image for Macs with Apple silicon and Intel Macs.
- **Linux (64-bit):** an AppImage, built on Ubuntu 24.04. Make the file executable, then run it.
- **SHA256SUMS.txt** lists each file's checksum.
