JusPrin 2 is a new app, not an update of JusPrin 1. It is built on OrcaSlicer 2.5.0, and every project has AI working beside it. You tell AI what you are printing and what went wrong. AI reads your file, your settings and your slice, changes the settings and slices again.

## What AI can do

Each project has an AI chat beside the 3D view. Ask in plain words, and AI works in the open project:

- Set up the printer, filament and print settings for the part you are printing.
- Open a model or project file, place objects on the plate, and lay out plates.
- Cut, split, merge and repair objects.
- Change print settings for you.
- Slice the plate and check the result, for example support printed inside a hole, or a part that starts in the air.
- Look at a photo of a failed print and suggest what to change.
- Run a filament calibration test (temperature, flow or pressure advance), read a photo of the printed test, and save the result as a new filament preset.

When you ask AI to print, it opens the usual send dialog. You choose the options and press Send. AI never starts a print.

When a slice has a problem, a marker on the 3D view shows it. Press Ask AI to have AI explain the problem and your options.

## Ways to use AI

- Sign up for a JusPrin account in the app. New accounts get free credits, and no card is needed.
- Use your own OpenAI, Anthropic or OpenRouter API key.
- Connect an AI app you already use: Claude Code, Codex, Claude Desktop or Cursor. It can then work with the project open in JusPrin.
- Or skip AI and just slice.

## Also new

- **Home screen.** Your projects and printers are on one screen. Each printer card shows the printer's status, and opens the printer's own window.
- **Printers.** Add a printer and connect it by chatting with AI. Bambu Lab, Klipper (Moonraker) and OctoPrint printers can be connected.
- **Saving.** Projects save themselves, so JusPrin never asks you to save or discard. File › Save (Cmd+S on a Mac, Ctrl+S on Windows and Linux) keeps a version you can go back to in File › Version history. Saving doesn't write over the .3mf file you opened. To get a .3mf file, use File › Export › Project 3MF (Cmd+Shift+S or Ctrl+Shift+S).
- **Opening files.** A file you open from Finder or File Explorer opens as a new project. A model dropped on the 3D view is added to the open project.
- **Check print.** Print › Check print shows a report of the slice beside the preview.
- **Print history.** Every sliced file you export or send to a printer is listed on Home's Print history, and you can print it again from there.
- **Classic view.** View › Switch to classic view shows OrcaSlicer's full interface. Press Back to JusPrin to return.
- **Updates.** JusPrin checks its GitHub releases for a new version once a day. You see the result in Preferences › Updates.
- **Reporting a problem.** Help › Report a problem opens a new GitHub issue in your browser, with the app's version and your system filled in.

## Upgrading from JusPrin 1.4

- **Installing.** On Windows, the installer replaces JusPrin 1. On a Mac, JusPrin 2 is also called JusPrin.app, so dragging it to Applications replaces JusPrin 1. On Linux, the AppImage is a new file, and JusPrin 1's AppImage stays where it is.
- **Your printers.** The first time JusPrin 2 starts, it offers to import your printers from JusPrin 1 or OrcaSlicer, with their filaments and print settings. You choose which printers to import. You can import later with File › Import › Import from JusPrin 1 or Import from OrcaSlicer.
- **Your JusPrin 1 folder.** JusPrin 2 keeps its settings in a new folder. It only reads JusPrin 1's folder and never changes it. JusPrin 1's app settings, such as units and language, aren't imported.
- **Your account.** Your JusPrin 1 sign-in doesn't carry over. To use AI with a JusPrin account, sign up in JusPrin 2, even if you had an account in JusPrin 1. Chats from JusPrin 1 aren't imported.

## Downloads

- **Windows (64-bit):** the installer, or the portable .zip, which runs without installing.
- **Mac:** one disk image for Macs with Apple silicon and Intel Macs.
- **Linux (64-bit):** an AppImage, built on Ubuntu 24.04. Make the file executable, then run it.
- **SHA256SUMS.txt** lists each file's checksum.
