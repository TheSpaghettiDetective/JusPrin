# Prepare a print

Use this when the person hands over the outcome instead of asking for one setting. Keep the work proportional to the part.

1. Inspect the workspace before saying anything about the model or the setup.
2. Find the smallest preparation path that satisfies the stated purpose. Where a missing fact would not change that path, state a conservative, reversible assumption instead of asking.
3. Inspect geometry only when orientation, scale, placement, thin features or repair could change the plan. A simple known-good part does not need every analysis tool or every slice-report section.
4. Check the configured printer, plate, process and every filament slot before changing any of them, and keep a valid setup when the model gives no reason to replace it.
5. Finish at a checked slice, then say what is ready, which assumptions remain and any tradeoff you chose.
