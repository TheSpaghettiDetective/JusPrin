**1. Yes — Delete Printer exists in the GUI.** It's a "Delete this preset" (❌) button on the Printer Settings tab toolbar (not a right-click context menu item on the combo box). It's shown/hidden dynamically depending on whether the selected printer is deletable.

**2. Implementation:**
- `src/slic3r/GUI/Tab.hpp:356` — `void delete_preset();` declaration; `m_btn_delete_preset` member (`Tab.hpp:158`).
- `src/slic3r/GUI/Tab.cpp:6801` — `Tab::delete_preset()`, the main handler. It confirms with the user, warns if other presets/filament/process presets inherit or depend on it, and calls `PresetCollection::delete_preset()` / `physical_printers.delete_preset_from_printers()`.
- `src/slic3r/GUI/Tab.cpp:5947` — `Tab::update_btns_enabling()` controls visibility: `m_btn_delete_preset-&gt;Show((m_type == Preset::TYPE_PRINTER &amp;&amp; m_preset_bundle-&gt;physical_printers.has_selection()) || preset.can_overwrite());`
- Backing collection logic: `src/libslic3r/Preset.cpp:3017` `PresetCollection::delete_preset()`, `src/libslic3r/Preset.cpp:4046` `PhysicalPrinter::delete_preset()`, `src/libslic3r/Preset.cpp:4347` `PhysicalPrinterCollection::delete_preset_from_printers()`.

**3. Yes, distinguished via `can_overwrite()`:**
`src/libslic3r/Preset.hpp:247`:
```cpp
bool can_overwrite() const { return !this-&gt;is_default &amp;&amp; !this-&gt;is_system &amp;&amp; !this-&gt;is_from_bundle(); }
```
Only presets that are not default, not system (vendor-bundled), and not from a bundle can be deleted. `Tab.cpp:6814` also specifically checks `!current_preset.is_system` for the "third-party printer" deletion confirmation dialog (warning that attached filament/process presets will be deleted too).
