Actually a bigger question is that w how we should handle the situation when a new chat Has changed the settings and rendered the old chats stale. In this case, should we still allow user to resume from one of the old chats? If so, should the conversation resume from the last checkpoint of the old chat, or the current state? If from the current state, The old chat itself may not make sense, e.g., the old chat made 5% infill for quick print, but a more recent chat has changed it to 80% for a strong print. now a chat that appears to have a quick print purpose inherited a ridiculously high infill.&#x20;

This dilemma probably is similar to the examples that you have found. Tell me how they were addressed by replit or claude artifacts.
