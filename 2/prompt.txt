in sidechat:

The easiest is to use a icon library, Instead of adding icons on case by case basis, right?
8:59 PM
Worked for 1m
Yes. A consistent SVG icon library is a better source than drawing and cataloging each glyph ad hoc. A library such as [Lucide](https://lucide.dev/) provides a coherent style and SVGs whose size, color, and stroke can be adjusted.
For JusPrin, I’d choose **one icon source for Figma, React, and the native shell**, then import only the icons the product uses. The existing `Icon` component can define size and color; it does not need a new component for every glyph. A few product-specific symbols can remain custom. The key is using the *same artwork* across all three surfaces—adding a React icon package alone would leave the native UI and Figma out of sync.
