Task:
Find out whether JusPrin 2.0.1 still has the two faults a YouTube reviewer named on camera about JusPrin 1, by running his two tests on the real app. This is a measurement. Do not change any code or prompt, and do not fix anything you find.

**The two faults, in his words (video `K3Fmc98ug2I`, "These 13 New 3D Printing Apps Are Insane!", transcript 13:39 to 14:51):**
1. Asked to maximise strength while minimising weight, it "added tons of infill and perimeters".
2. It "added way excessive supports to any overhang, despite the angle".
He also said the changes were "mostly logical" and that he would recommend it to absolute beginners only. We do not have his exact prompts or his model files, only those sentences, so you choose reasonable ones and write down what you chose.

**What to run**
- Use the released JusPrin 2.0.1 (GitHub release `jusprin/v2.0.1` of `TheSpaghettiDetective/JusPrin`), or an existing local build of that tag if one is already there. Do not start a fresh full build for this; read "Building on a shared machine" in `AGENTS.md` first if you think you need one.
- Go through the app's own AI chat beside the 3D view, signed in to a JusPrin account, with the model a new user gets by default. That is what a reviewer would do. The result depends on the app's own prompt and model, so driving the project from an outside AI app over MCP does not count as the test. You may use any means to read settings and slice results afterwards.
- Use an isolated `--datadir` and do not drive another running JusPrin instance. The project memory has recipes for driving the real app on this Mac and for a signed-in scratch app; `agent-docs/jusprin/README.md` has the verification method.
- Test 1 (strength against weight): on at least three different parts (for example a load-bearing bracket, a hook, a plain box), ask in plain words for the strongest part at the lowest weight. Record before and after: wall loops, sparse infill density and pattern, top and bottom layers, and the sliced filament weight. Say for each whether the change is a sensible trade (strength added where it counts, weight kept down) or the fault he described.
- Test 2 (supports): on parts with overhangs at several angles, including shallow ones that print fine without support and steep ones that do not, ask the AI to set the part up for printing, and separately ask whether it needs supports. Record whether supports were turned on, the support type and threshold angle, and how much support material the slice contains. Say whether it supports everything regardless of angle.
- Run each case more than once, because replies vary from run to run. Say how many runs each figure rests on.
- If a JusPrin 1.4 build can still run and sign in, run one or two of the same cases on it for comparison. Do not spend long on this; say so if it cannot be done.
