### Compatibility with the current printer

`is_compatible` is a **cached flag**, not computed on read. It is written only by `PresetCollection::update_compatible_internal` (`Preset.cpp:3340-3385`), reached through `PresetCollection::update_compatible` (`Preset.hpp:755-764`) and `PresetBundle::update_compatible` (`PresetBundle.cpp:5300`). Callers are all GUI/selection-change sites (`Tab.cpp:1459, 5034, 6202, 6741`, `MainFrame.cpp:3764`, `GUI_App.cpp:7177`, `PresetBundle.cpp:542, 811, 826, 1060`).

The rule itself, `Preset.cpp:809-841`:
```cpp
bool is_compatible_with_printer(const PresetWithVendorProfile &amp;preset, const PresetWithVendorProfile &amp;active_printer, const DynamicPrintConfig *extra_config)
{
    // Orca: check excluded printers
    if (preset.vendor != nullptr &amp;&amp; preset.preset.type == Preset::TYPE_FILAMENT) { ... m_excluded_from ... }
    auto &amp;condition               = preset.preset.compatible_printers_condition();
    auto *compatible_printers     = dynamic_cast&lt;const ConfigOptionStrings*&gt;(preset.preset.config.option("compatible_printers"));
    bool  has_compatible_printers = compatible_printers != nullptr &amp;&amp; ! compatible_printers-&gt;values.empty();
    if (! has_compatible_printers &amp;&amp; ! condition.empty()) {
        try { return PlaceholderParser::evaluate_boolean_expression(condition, active_printer.preset.config, extra_config); }
        catch (const std::runtime_error &amp;err) { ...; return true; }   // parse error ⇒ "compatible with everything"
    }
    return preset.preset.is_default || active_printer.preset.name.empty() || !has_compatible_printers ||
           std::find(...) != compatible_printers-&gt;values.end() ||
           (!active_printer.preset.is_system &amp;&amp; is_compatible_with_parent_printer(preset, active_printer));
}
```

Two mechanisms, in priority order: the `compatible_printers` **list** of printer preset names wins; only when that list is absent/empty is the `compatible_printers_condition` **expression** evaluated.

**Nozzle-specific compatibility** has no dedicated API. It rides on the condition expression, which is evaluated against the *active printer's config* — so `nozzle_diameter[0]` resolves to the selected printer. Real examples in this tree:

### Can enumeration or compatibility evaluation mutate?

Yes, in three distinct ways. In decreasing severity:

1. **`PresetCollection::update_compatible(...)` selects a different preset.** `Preset.hpp:755-762`:
   ```cpp
       if (this-&gt;update_compatible_internal(...) == (size_t)-1) {
           size_t index = this-&gt;first_compatible_idx(prefered_condition);
           this-&gt;select_preset(index);
       }
   ```
   and `update_compatible_internal` itself clears the selection (`Preset.cpp:3365-3370`), writes `is_compatible` on every preset (`:3360, 3372`), and flips default-preset `is_visible` (`:3375-3381`). `select_preset` then resets `is_dirty = false` on *every* preset and rebuilds `m_edited_preset` (`Preset.cpp:3573-3579`). **Never call this from a read-only tool.** Read the cached `is_compatible` flag, as `SetupCommands::compatible_filaments` does.

2. **`Preset::compatible_printers_condition()` and `inherits()` insert a config key.** Both use `cfg.option&lt;...&gt;(key, /*create=*/true)` (`Preset.hpp:319, 338, 346`), and `DynamicConfig::optptr(key, true)` inserts a default-constructed option into the map (`Config.cpp:1562-1583`). The `const` overloads `const_cast` their way there (`Preset.hpp:321, 343, 351`). `is_compatible_with_printer` calls `preset.preset.compatible_printers_condition()` at `Preset.cpp:825` — so **evaluating compatibility yourself writes to the preset's `DynamicPrintConfig`**.
   It does not in practice create a spurious dirty: the inserted value is the default (empty string) and `ConfigBase::diff` ignores keys missing from either side (`Config.cpp:518-528`). But it is a non-const write to shared state from a nominally read-only path — relevant if you ever touch presets off the main thread.

3. **`get_selected_preset()` (non-const) can change the selection.** `Preset.hpp:623-629`:
   ```cpp
       Preset&amp;         get_selected_preset() {
           if ((m_idx_selected &lt; 0) || (m_idx_selected &gt;= m_presets.size())) { select_preset(first_visible_idx()); }
   ```
   The `const` overload (`:630`) does not. Hold the bundle as `const PresetBundle*` — as `SetupCommands.cpp:58` and `OrcaWorkspaceAdapter.cpp:248` do — and this cannot fire.

Safe reads: iterating `begin()/end()` or `get_presets()`, `get_selected_idx()`, `get_selected_preset_name()`, the const `get_selected_preset()`/`get_edited_preset()`, `current_is_dirty()`, `current_dirty_options()`, `get_preset_with_vendor_profile()`, `first_visible_idx()`, `num_visible()`. Not safe: `update_dirty()` (`Preset.hpp:794`, writes flags), `select_preset*`, `update_compatible*`, `set_default_suppressed`, `discard_current_changes`.

Reading a preset does **not** touch the workspace revision. Revision only advances through `OrcaWorkspaceAdapter::publish_change` → `Workspace.hpp:440` (`++m_state-&gt;revision`); `snapshot()` reads it const at `OrcaWorkspaceAdapter.cpp:239`.
