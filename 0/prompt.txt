## Why

On 2026-10-15 another agent ran live conversations against the app and found two faults in how the assistant chooses a print setup, neither of which the project prompt harness (`tests/project_prompt`, read its README first) can see, because no case covers them:

1. On "I want to print this", with a model loaded and a PLA setup already selected and no purpose stated, one run in three sliced the existing setup at once instead of asking what the part is for. The prompt's When-to-act section says "Ask when the answer is theirs, since it is their print and printer: what the object is for, a risk to the printer…", so the expected first step is one question, not a tool call that changes or slices anything.
2. After switching the filament to Bambu PETG HF, the assistant did not notice the project's plate is a Cool Plate, which PETG cannot slice on. The expected first step at that point is a `printer_setup_preview` that would surface the mismatch, or a question or statement about the plate, and never `slice_start`.
