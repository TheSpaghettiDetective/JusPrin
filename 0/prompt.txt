**1. Accounts and sign-in**
- The only sign-in server is `https://jusprinv2.obico.io` (`Agent/ProviderProfile.hpp:71`, `Agent/CloudAccount.hpp:212`). It can be changed through the AppConfig setting `jusprin_server/base_url` (`Agent/AgentConfiguration.cpp:24,36`) or the env var `JUSPRIN_AGENT_ENDPOINT` (`Agent/ProviderFactory.cpp:126`).
- Browser sign-in uses OAuth with PKCE, returning to `127.0.0.1:41172`. The token is fetched from `/o/token/` and revoked at `/o/revoke_token/` (`Agent/CloudAccount.cpp:105-127,405`).

The OS keychain is deliberately not used (`Agent/AgentConfiguration.hpp:31-35`).

**2. AI chat**
- Four providers are possible: the JusPrin gateway at `jusprinv2.obico.io/ent/jusprin/v2/responses` or `/messages`, OpenAI at `api.openai.com`, OpenRouter at `openrouter.ai` (adds `X-Title: JusPrin`), and Anthropic at `api.anthropic.com` (`Agent/ProviderProfile.hpp:71-86`).
- DeepSeek and Google are not providers. DeepSeek is only reachable as a model through OpenRouter (it appears only in a test, `AgentUI/src/components/ModelPickers.test.tsx:13`). Direct Google/Gemini: not found.
- With your own key, requests go straight from the desktop to the provider. With an account, they go to the JusPrin gateway, which forwards them to the provider (`Agent/ProviderProfile.hpp:45-57`). The gateway's own model names (like "slicer-1") map to providers chosen on the server side, which is not in this repo.
- Your own key: yes, for OpenAI, OpenRouter or Anthropic. It is stored in plain text in AppConfig as `&lt;provider&gt;_api_key` (`Agent/AgentConfiguration.cpp:154-166`).
- A request contains:
  - the typed text and any print-issue details (`Agent/ProviderAgent.cpp:291-293`);
  - a project summary: project name, printer/filament/process preset names, plate and object names, selection, plan, and G-code history with export file names and printer names (`Agent/ProviderAgent.cpp:38-120,295`);
  - attachments: name and text, plus image and PDF bytes (`Agent/ProviderAgent.cpp:296-316`).
- Tool results add plate pictures (`view_render`), project images (`Agent/ToolRegistry.cpp:1238-1250`), mesh measurements from `object_analyze` (`Workspace/Workspace.hpp:355-373`) and settings values. Raw mesh files are only sent if image/PDF counts; otherwise not found.
- Extra request fields:
  - Headers to the gateway: `X-JusPrin-Turn`, `X-JusPrin-Request`, and `X-JusPrin-Chat`, a SHA-256 hash of the chat key (`Agent/ProviderAgent.cpp:441-447,719`).
  - OpenAI and OpenRouter get `"store": false`, plus `prompt_cache_key`, which is the unhashed project/conversation ID (`Agent/ResponsesCodec.cpp:120,129-130`).
  - The provider's own web search tool is offered (`Agent/AnthropicCodec.cpp:92`).

**3. Chat history**
- Chats are saved locally in the project state under `&lt;data_dir&gt;/jusprin/projects` (`Shell/ShellController.cpp:383`, `Agent/ProjectPersistence.cpp:200-209`). Chat titles go in `&lt;data_dir&gt;/jusprin/chat-titles.json` (`Agent/AgentWebView.cpp:78`).
- There is a local request log that is on by default with no switch found.
