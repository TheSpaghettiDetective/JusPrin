## The problem

Every project chat turn carries a `<workspace>` block built by `workspace_json()` in src/slic3r/GUI/JusPrin/Agent/OpenAIResponsesAgent.cpp (commit a86c3edb91, 2026-10-15). Each plate is sent as id, name, active, sliced and its objects. The plate type (Cool Plate, Textured PEI, Engineering, High Temp, and so on) is not there. In live conversations on 2026-10-15, the assistant switched a project to Bambu PETG HF without noticing the project started on a Cool Plate, which PETG cannot slice on; it then ran into the slice and stalled. `printer_setup_preview` does report the mismatch, but only when the model thinks to call it. The prompt's Preparing section says to set a printer, filament and process that suit the print; the plate is the fourth thing it should see.

## What to do

1. Add the plate type to each plate in the snapshot, using the same name `printer_setup` and `printer_setup_preview` use for it (`plateType` / `bedType`; look at `ToolRegistry.cpp` around the printer_setup schema and at how `WorkspaceSnapshot` exposes the plate's bed type, and at `plate_layout`'s `bedType`), so the model sees one vocabulary. If the workspace snapshot does not already carry the bed type per plate, add it to `Workspace::WorkspaceSnapshot` and fill it in `OrcaWorkspaceAdapter`, read from the plate the way `plate_layout` writes it. Omit the field when there is no value rather than sending null.
2. Keep the snapshot small and byte-stable across turns when nothing changed.
3. Update the unit tests in tests/agent/test_openai_responses_agent.cpp (the part-by-part request body check) and the workspace contract tests if the snapshot struct changes. Add one test that a plate's type appears in the `<workspace>` block.
4. The project prompt harness (tests/project_prompt, see its README) replays requests recorded from the app in `requests.json`; the snapshot shape changing means the recording must be made again with `--project-prompt-requests` (no model call), as commit 76cd05f459 did. Do that and note in the README which change the re-recording was for.
5. Do not change the prompt text. Do not run a live batch.
